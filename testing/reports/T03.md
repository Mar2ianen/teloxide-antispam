# T03 — URL grammar, canonicalization, and metamorphic properties

Status: implementation/tests complete locally; CI and focused PR are pending.

## Scope

Added deterministic URL grammar tests in `crates/teloxide-url/tests/url_grammar.rs` plus a small public synthetic corpus at `testing/corpus/public/url_grammar_synthetic.jsonl`. Production parser behavior was not changed because the new oracles found no parser defect.

The hand-authored expected values cover scheme and hostname case folding, HTTP/HTTPS default ports, retained non-default ports, path and query case, fragments, empty query delimiters, duplicate query keys, percent escapes, Unicode IDN host/path/query serialization, IPv6 literals, credentials, and `.invalid` host-confusion cases. Telegram-specific checks include `tg:` URI parsing, `t.me@evil.invalid`, `t.me.evil.invalid`, and a synthetic Telegram username. URLs are parsed only as strings; no network request is made.

## Reproducible lanes

- Seed: `0x5eed2026111603`.
- V2 grammar lane: 2,048 generated, grammar-constrained URLs. Accepted: 2,048/2,048 (100%); rejected: 0/2,048.
- V3 byte-mutation lane: 1,000 deterministic mutations from valid templates across unsupported scheme, invalid port, malformed IPv6 authority, and authority delimiter corruption. Rejected: 1,000/1,000 (100%); accepted: 0/1,000.
- Public fixture corpus: 5 V2 synthetic cases and 2 V3 invalid cases. It contains only `example.org` or `.invalid` hosts and synthetic values; it includes evidence source, validity, parser revision, and cross-field assumptions.
- Parser/canonicalization checks complete in approximately 0.03 seconds locally. No failing randomized case or minimized counterexample was found.

## Verified invariants

- Parse/canonicalize is stable and idempotent for generated supported URLs.
- Host case folding and default-port elision match fixed expected canonical strings; path/query case, duplicate parameters, fragments, and empty query delimiters remain significant.
- A single semantic target assigned each of the four URL sources produces one identity; deliberately changed path/query-case targets stay distinct.
- Credentials do not make a lookalike host Telegram-owned, and `.invalid` lookalike hosts are not classified as Telegram links.
- Out-of-range/malformed URL strings reject, and `find_urls` stays within configured result and item-size bounds on byte-mutated inputs.
